# Android Frameworks Base (LineageOS 18.1 / VortexOS)

Core Android framework layer with gaming enhancements, custom battery styles, and fluid animations.

---

## Features

1. **Gaming Enhancements & Spoofing (`GamePropsUtils.java`)**:
   * Flagship device spoofing for unlocked graphic/FPS settings in games (90 FPS in BGMI).
   * Game mode notification management.

2. **Battery Styles Suite**:
   * Landscape, Capsule, iOS 15, OneUI, and Android 16-inspired battery styles.

3. **Biometric Face Unlock Service**:
   * Integrated `CustomFaceService` support.

4. **Gesture & UI Enhancements**:
   * 3-finger swipe-to-screenshot (`SwipeToScreenshotListener.java`).
   * Android 12 themed icon integration (`SimpleIconFactory.java`).
